# PulseWeaver

Windows向けの無料オーディオミキサー試作です。マイク・バーチャル入力・**アプリごとの音**を個別の音量で混ぜ、物理出力（A）と仮想出力（B）へ自由に振り分けます。

## 実行

必要なもの:

- Windows 11（アプリ単位の取り込みを使う場合は Build 20348 以降。それ以外の機能は Windows 10 でも動作します）
- .NET 8 SDK
- 仮想オーディオケーブル（任意。例: [VB-CABLE](https://vb-audio.com/Cable/)、Yamaha SYNCROOM Driver）

```powershell
dotnet run --project .\PulseWeaver\PulseWeaver.csproj
```

VB-CABLE は公式配布元から別途インストールしてください。このアプリはドライバーを同梱・再配布しません。仮想出力に CABLE Input、Discord の入力デバイスに CABLE Output を選択します。

## 現在の範囲

- **入力は追加・削除・並び替えが可能**（3種類の入力ソース）
  - **H/W入力** … マイク・ライン入力などの録音デバイス
  - **バーチャル入力** … 指定した再生デバイスの音をループバックで取り込み
  - **アプリ入力** … 特定のアプリ（プロセスツリー）の音だけを取り込み
- **出力も追加・削除・並び替えが可能**
  - **A（物理出力）** … スピーカー・ヘッドホンなど
  - **B（仮想出力）** … CABLE Input や SYNCROOM Driver など。受け側のアプリからマイクとして扱える
- 入力ごとの **音量 / ミュート / ソロ**、出力ごとの音量（すべて動作中に即時反映。音量は dB 表示で 0 dB がそのままの音量、+6 dB まで増幅可能）
- **低遅延の音声処理**（取り込みバッファ 100 ms、出力バッファは既定 50 ms。設定で出力バッファを調整可能。負荷が高い環境でも途切れにくいよう、再生開始前にわずかに予備バッファリングします）
- 入力・出力それぞれの**レベルメーター**を縦型のチャンネルストリップで表示（緑 → 黄 → 赤の 3 段階）
- 入力ストリップの **3D 定位**（前後左右のパッド）と **COMP / GATE** のつまみ、**MONO** ボタン
- 出力ストリップの **MONO / EQ（3 バンド）/ ミュート**
- デバイスの選択は**ポップアップ＋再スキャン**。アプリを再起動しなくても、後から接続した無線ヘッドホンなどを選べる
- 選んだ**デバイス名も構成に保存**。未接続でも「デバイス名（未接続）」と表示し、ID が変わっても名前で自動的に再照合
- 入力ごとの **レベルメーター**
- **マイクモニター** … 入力ごとに送り先の出力と専用音量を指定して自分の声を確認
- **仮想オーディオデバイスの自動検出**（VB-CABLE / VoiceMeeter / SYNCROOM など）と、対応する録音デバイスの案内
- 入力・出力の名前は自由に変更可能（クリックして編集、設定に保存）
- 構成（プロファイル）の保存・切替（`usr/settings` 内の JSON を選択すると即時に切替）
- 構成のエクスポート／インポート、選択中の構成への上書き保存
- Windows 起動時の自動起動、タスクトレイ常駐（バックグラウンド起動）
- 起動時にミックスを自動開始、起動時に適用する既定の構成を選択
- 出力先と入力デバイスが同じになる組み合わせは既定で回避し、開始時にもハウリングの警告を表示
- 一部のデバイスが他アプリに占有されていても、残りのデバイスで動作を継続
- 上部タブ（ミキサー / 設定）で操作と設定を分離
- 設定はジャンル別（一般 / 音声 / 構成 / 更新情報 / このアプリについて）
- 自動アップデート確認（起動時・24時間に1回）と、アプリからのインストール
- 更新情報に過去のリリース履歴を表示

## アプリごとに音を分ける

「入力」の **＋ アプリ** から取り込むアプリを選ぶと、そのアプリの音だけを 1 本のストリップとして扱えます。Discord・ゲーム・ブラウザをそれぞれ別の音量・ミュート・振り分けで扱いたいときに使います。

- 取り込みは**プロセス単位（Application Loopback）**で行うため、出力先デバイスに縛られません。子プロセス（Chrome の音声プロセスなど）もまとめて取り込めます。
- アプリの音は元の出力先にも流れ続けます。他の人に聞かせたくない場合は、そのアプリの出力先を仮想出力（CABLE Input など）にしてください。**ケーブル 1 本で複数アプリを分離できる**のがこの方式の利点です。
- 次の音は取り込めません: DRM で保護された音声、排他モード／ASIO を使うアプリ。
- アプリが終了した場合は検出して自動で再捕捉します（プロセス名で追跡）。
- この機能は Windows 11（Build 20348 以降）が必要です。

## ミュート・ソロ・モニター

| 操作 | 場所 | 内容 |
|---|---|---|
| M | 入力・出力ストリップ | ミュート（振り分けは保持したまま無音にする） |
| S | 入力ストリップ | ソロ（ソロ中の入力だけを鳴らす） |
| MONO | 入力・出力ストリップ | モノラル化 |
| EQ | 出力ストリップ | 3 バンド EQ の ON/OFF（右クリックで低域・中域・高域を調整） |
| MON | 入力ストリップ | マイクモニターの有効化。送り先と音量は 設定 &gt; 音声 で指定 |
| 🎤 / 🔊 | メーターの下 | ミュートの切り替え（マイク＝入力、スピーカー＝出力。ミュート中は赤と斜線） |

フェーダーのつまみを**右クリック**すると、その値（dB）を数値で入力できます。0.1 dB 単位で指定でき、`.0` は表示では省略されます（例: `0`、`-6.5`、`3`）。右端まで下げると `-∞`（無音）になります。

モニター音量はその出力にだけ掛かるので、配信・通話へ送る音量とは別に自分の声の大きさを調整できます。

## 3D 定位・COMP / GATE

入力ストリップのパッドをドラッグすると、音源を前後左右に置けます（左右は音量バランス、前後は距離感＝減衰と高域の丸まり）。右クリックで中央に戻ります。

**COMP** と **GATE** のつまみは 0〜10 で効きを調整します（0 でオフ）。上下のドラッグで回し、ダブルクリックで 0 に戻ります。

## アップデート

起動時に24時間以上経過していれば、GitHub のリリースを自動確認します（設定 > 一般 で無効化可能）。新しいバージョンがある場合はミキサー画面に案内が出て、設定 > 更新情報 から次の操作ができます。

- **最新かどうかを調べる** … 現在のバージョンと最新リリースを比較
- **アップデートする** … インストーラーをダウンロード（SHA-256 検証あり）して起動し、アプリを終了（インストール完了後に自動で起動し直します）
- **リリースページを開く** … ブラウザーで GitHub のリリースを開く

インストーラー版で導入している場合、そのまま上書き更新されます。インストールが終わると PulseWeaver が自動で起動し直します（手動でセットアップを実行した場合は完了画面の「PulseWeaver を起動」で起動できます）。更新情報には過去のリリース履歴と変更内容が表示され、各行をクリックするとリリースページを開きます。変更内容は [CHANGELOG.md](./CHANGELOG.md) を読み取って表示します（取得できない場合はアプリに同梱した内容を使用）。

## 構成（プロファイル）

設定 > 構成 から、現在のデバイス割り当て・音量・振り分け・名前をまとめて保存／切替できます。

- 保存先: `usr/settings/<名前>.json`（アプリの実行ファイルと同じフォルダ）
- 一覧から選択すると**即座に切り替わります**（ミックス中なら自動で再起動）
- 手動で置いた JSON も「再読み込み」で一覧に表示されます
- 「エクスポート」「インポート」で任意の場所とやり取りできます
- 「選択中に上書き」で、選んでいる構成を今の設定で置き換えられます（同名保存時も確認あり）

0.0.6 以前の構成ファイル（固定長の配列形式）は、読み込み時に自動で新しい形式へ移行します。

## 自動起動とバックグラウンド動作

設定 > 一般 から設定できます。

| 設定 | 内容 |
|---|---|
| Windows 起動時に自動起動 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に `PulseWeaver` を登録 |
| バックグラウンドで起動 | タスクトレイに常駐し、閉じるボタンでトレイへ格納（ミックスは継続） |
| 起動時にミックスを自動開始 | 起動直後に保存済み（または既定の構成）の設定でミックスを開始 |
| 起動時に適用する既定の構成 | 起動時にその構成を適用（「（現在の設定）」なら前回のまま） |

自動起動とバックグラウンド起動を併用すると、`PulseWeaver.exe --minimized` として登録され、タスクトレイで静かに起動します。トレイのアイコンを左クリックすると画面が戻り、右クリックメニューからも表示／ミックス開始・停止／終了を選べます。

設定とログの保存先:

- 動作中の設定: `%LOCALAPPDATA%\PulseWeaver\settings.json`
- ログ: `%LOCALAPPDATA%\PulseWeaver\logs\app-<日付>.log`（設定 > このアプリについて から開けます）

音声が開始できない場合は、ログに失敗したデバイス名と HRESULT（例: `0x8889000A` = デバイスが排他使用中）が記録されます。

## 配布物のビルド

GitHub Actions の `.github/workflows/release.yml` が、タグ push（例: `v0.1.0`）でインストーラと ZIP を作成してリリースします。ローカルで作る場合:

```powershell
dotnet publish .\PulseWeaver\PulseWeaver.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:Version=0.1.0 -o dist\publish
iscc /DVERSION=0.1.0 .\installer\PulseWeaver.iss
```

インストーラは [Inno Setup 6](https://jrsoftware.org/isdl.php) でビルドします（商用配布にはライセンス購入が必要です）。
